Primeira versão com numeração própria. A API Pawn continua a **R39-6**: as natives e o `a_mysql.inc` são compatíveis, então gamemodes existentes funcionam sem alteração. Basta trocar o binário.

## Instalação

| Arquivo | Uso |
| --- | --- |
| `mysql-plugin-linux-x86.zip` | `mysql.so` (usa o OpenSSL 1.1 do sistema) e `mysql_static.so` (OpenSSL embutido, sem dependências extras) |
| `mysql-plugin-windows-x86.zip` | `mysql.dll` |
| `a_mysql.inc` | include Pawn |
| `SHA256SUMS.txt` | hashes para conferir os downloads |

Os binários são 32 bits, como os servidores SA:MP e open.mp.

## Correções

- **Callbacks e queries não são mais descartados sob carga.** As filas internas tinham tamanho fixo. Com muitas queries pendentes, a query rodava no banco, mas o callback era perdido, ou a native devolvia 0 com a fila cheia. Agora as filas crescem conforme a necessidade.
- **Reconexão mais confiável.** `mysql_reconnect` não deixa mais a conexão fechada quando há queries pendentes. Conexões com auto-reconnect tentam de novo em segundo plano (de 1 s a 30 s) quando o banco está fora do ar na inicialização ou cai (erros 2006/2013). As tentativas de conexão expiram em 10 s.
- **Conexão após falha.** Depois de uma tentativa de conexão falha, todo `SELECT` seguinte falhava com o erro 5027. Corrigido.
- **Log seguro entre threads.** Com o banco fora do ar, várias conexões registravam erros ao mesmo tempo e podiam corromper ou misturar linhas do `mysql_log.txt`.
- **Menor latência.** As threads de query acordam assim que chega trabalho, em vez de verificar a fila a cada 10 ms.
- Resultados incompletos não são mais entregues aos callbacks quando a leitura do resultado falha. IDs de conexões, ORMs, caches, statements e transações são reaproveitados com segurança.

## Por dentro

- Sem Boost: C++17 e um único build com CMake para Linux e Windows. O `mysql.so` ficou cerca de 290 KB menor. A conversão de números (`mysql_format %f`, `cache_get_row_float`/`int`) gera saída idêntica à anterior; isso foi verificado para todos os 4,3 bilhões de valores `float`.
- Cada versão passa por testes automáticos contra MySQL 8.4, MySQL 5.7 e MariaDB 11.4, com AddressSanitizer, UBSan, LeakSanitizer e ThreadSanitizer.
